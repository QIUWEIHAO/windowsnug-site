Privacy Policy

Window Snug for macOS · Last updated 16 August 2026

Window Snug does not collect, store, or transmit any personal data. There are no accounts, no analytics, no advertising, no crash reporting, and no network requests of any kind.

What the app stores

Your keyboard shortcut preferences and the "launch at login" setting are saved locally on your Mac using macOS's standard preferences system (UserDefaults), inside the app's sandbox container. This data never leaves your device and is removed when you delete the app.

Accessibility access

To move and resize windows, Window Snug uses Apple's public Accessibility API, which macOS gates behind an explicit permission you grant in System Settings › Privacy & Security › Accessibility. The app uses this access solely to read a window's position and size and to set a new position and size. It does not read window contents, keystrokes typed into other applications, text, screenshots, or any other information, and it does not record or transmit anything it observes. You can revoke this permission at any time in System Settings.

Third parties

Window Snug contains no third-party SDKs, frameworks, trackers, or analytics libraries. No data is shared with anyone, because none is collected.

Children

The app is rated 4+ and collects no data from users of any age.

Changes

If this policy ever changes, the updated version will be posted on this page with a new "last updated" date. Any change that affects how data is handled will also be described in the app's release notes.
